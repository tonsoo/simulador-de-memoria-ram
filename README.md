# Simulador de Computador
Um simulador de computador com suporte para execução de scripts com sintaxe semelhante a Assembly, program counter, memória ram e terminal.

O projeto foi desenvolvido para disciplina de Arquiterura e Organização de Computadores da Universidade Tuiuti do Paraná, lecionada no segundo período do ano letivo de 2023.

# Comandos e especificações:

Veja a lista completa de comandos no terminal em [Comandos](COMMANDS.md).

O sistema segue uma arquitetura simples de 8bits, com um total 256 bytes de memoria, 4 registradores e 1 terminal para execução de comandos.
